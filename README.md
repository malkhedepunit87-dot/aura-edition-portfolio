# Aura|Edition Portfolio — Blue & White Theme

This package contains the updated GitHub Pages website in an icy blue, white, and soft lavender palette inspired by the provided Aura|Edition logo. The existing video section is preserved.

## Update on GitHub using Android
1. Download and extract this ZIP on your phone.
2. Open https://github.com/malkhedepunit87-dot/aura-edition-portfolio
3. Open the repository and choose **Add file → Upload files**.
4. Upload the included `index.html` and `README.md`, replacing the old files if prompted.
5. Commit the changes to the `main` branch.
6. Wait a few minutes, then refresh https://malkhedepunit87-dot.github.io/aura-edition-portfolio/

## Video notes
- Gallery selection is a local preview on the device; it does not permanently upload the video for other visitors.
- The YouTube option embeds a valid YouTube link when embedding is allowed.
- To make a Gallery video visible to everyone, host the video online and link to the hosted file.
